# Tournament Aggregator

Веб-приложение для просмотра турниров по игре UNO.

- **[Предметная область]**
  Турнирный агрегатор собирает в одном каталоге информацию о соревнованиях по UNO.
  Для каждого турнира указаны название, описание, количество участников, призовой
  фонд, дата и время, место проведения, формат и статус регистрации.

- **[Пользовательские сценарии]**

## Пользователи и сценарии

### Участник

**Цель:** найти подходящий турнир и узнать условия его проведения.

- **Главная страница** — открывает `/` и видит адрес каталога турниров.
- **Список турниров** — переходит на `/tournaments` и видит доступные турниры с основной информацией.
- **Подробнее о турнире** — выбирает турнир и переходит на `/tournaments/{id}`.
- **Несуществующий турнир** — открывает неверный id и получает страницу с ошибкой 404.

### Организатор

**Цель:** представить турнир потенциальным участникам.

- Публикует основные сведения о турнире в общем каталоге.
- Предоставляет подробное описание формата, места и времени проведения.
